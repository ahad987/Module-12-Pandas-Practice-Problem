# Module 12: Pandas Practice Problems

## 📌 Overview

This repository contains hands-on practice problems and solutions using **Python Pandas**, designed for beginners who are starting their journey in Data Science and Data Analysis.

The main objective of this module is to develop a strong understanding of Pandas fundamentals through practical coding exercises, data manipulation, indexing, sorting, and filtering.

All exercises were practiced using **Google Colab**.

## 🎯 Learning Objectives

By completing this module, you will learn how to:

- Create and manipulate Pandas Series.
- Create Pandas DataFrames using Python dictionaries.
- Understand DataFrame rows, columns, indexes, and data types.
- Explore datasets using `shape`, `dtypes`, and `describe()`.
- Access specific rows and columns using `loc[]` and `iloc[]`.
- Drop unnecessary rows and columns using `drop()`.
- Sort DataFrames using `sort_values()`.
- Filter data using conditional expressions.
- Apply multiple conditions to filter datasets.
- Perform basic exploratory data analysis (EDA).

## 📚 Practice Problems

This module covers the following 7 practice problems:

### Problem 01: Pandas Series and DataFrame Creation

- Create a Pandas Series from a Python list.
- Print Series values, index, and data type.
- Create a DataFrame with Name, Age, and City columns.
- Understand one-dimensional and two-dimensional data structures.

### Problem 02: DataFrame Information and Summary Statistics

- Find the total number of rows and columns using `shape`.
- Display column data types using `dtypes`.
- Generate statistical summaries using `describe()`.
- Understand basic statistical information such as mean, standard deviation, minimum, and maximum.

### Problem 03: DataFrame Columns, Indexing, and Data Access

- Create a DataFrame using a Python dictionary.
- Display column names using `columns`.
- Display row indexes using `index`.
- Access a single column.
- Access a complete row.

### Problem 04: Data Selection Using loc[] and iloc[]

- Access the first row using `loc[]` and `iloc[]`.
- Select the second column.
- Extract a 2×2 block from the DataFrame.
- Understand the differences between label-based and position-based indexing.

### Problem 05: Dropping Rows and Columns

- Create a 4×3 student marks DataFrame.
- Remove a specific column using `drop()`.
- Remove a specific row using its index.
- Understand the difference between `axis=0` and `axis=1`.

### Problem 06: Sorting DataFrames

- Create an employee DataFrame.
- Sort employee records by Salary in ascending order.
- Sort employee names in descending order.
- Practice sorting by multiple columns.

### Problem 07: DataFrame Filtering

- Create a DataFrame containing 8 students and their scores.
- Filter students with scores greater than 60.
- Filter students with scores less than 40.
- Practice conditional filtering using comparison operators.
- Apply multiple filtering conditions using AND (`&`) and OR (`|`).

## ⚙️ Installation and Requirements

Make sure Python is installed on your computer.

Install Pandas using pip:

```bash
pip install pandas
```

Import Pandas into your Python environment:

```python
import pandas as pd
```

**Note:** Google Colab already provides Pandas in its standard environment, so additional installation is generally not required.

## 🚀 How to Run

You can run the practice notebook using either Google Colab or Jupyter Notebook.

**Option 1: Google Colab**

1. Download the `.ipynb` notebook from this repository.
2. Open [Google Colab](https://colab.research.google.com/).
3. Upload the downloaded notebook.
4. Run each cell step by step.
5. Observe the outputs and practice the exercises.
